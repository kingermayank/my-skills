# From strategy to visual territories

## Mine ideas before selecting an aesthetic

Start from an audience tension and the strategic promise. Combine the user's observations and taste with word association, metaphors, materials, local history, cultural references, and real audience language. Choose methods that help the assignment; there is no need to invoke a separate brainstorming workflow.

Verify historical claims and current cultural references before treating them as facts. Examine whether a reference is meaningful to this audience now. A personally nostalgic reference is not automatically audience insight.

Useful transformations include:

- Raw associations → a clustered word map.
- A strong cluster → descriptive phrases, visual metaphors, and reference-search terms.
- Emotional tension → a recognisable visual behaviour or material contrast.
- A concept → signature elements and a set of supporting motifs.

Explore about three meaningfully distinct territories when the user wants options. Vary the underlying story or organising idea, not just the accent colour. A territory card should include a name, one-line story, audience emotion, link to positioning/pillars, signature device, supporting elements, typography, colour logic, imagery, layout/material/motion cues, risks, and criteria for success.

## Read references as design decisions

Analyse one source at a time before combining lessons from it. Ask:

- How is it constructed: proportion, mass, spacing, hierarchy, rhythm?
- What tension gives it character: precise/rough, restrained/expressive, familiar/unexpected?
- What has been deliberately left out?
- Which principle transfers to this brand, and what must change?

For external reference work, extract principles that can produce original execution. For the brand's own approved work, extract detailed visual rules to extend its system. These are different jobs. Do not average several reference images before understanding what each contributes.

The course favours strategically explained studio work and design publications. Its reference list includes Pentagram, Wolff Olins, DesignStudio, Studio Dumbar, COLLINS, BP&O, Visuelle, Creative Boom, and It's Nice That. These are research leads, not a requirement to browse all of them or a licence to reuse their assets. Honour user-provided references first.

## Explore type and colour in context

Within a promising territory, test a dependable option, a culturally current option, and an unexpected option if useful. Keep all three connected to the story. Verify font existence, available weights, language coverage, and relevant licences before specifying it for production. Set the actual brand name and representative copy; a font name alone does not show the relationship.

Give colours explicit roles and exact values: dominant/primary, supporting/secondary, neutral/background/text, and accent. Test ratios and real usage, not isolated attractive swatches. Swatch labels can use the brand's vocabulary, but preserve unambiguous values. Use deterministic swatch rendering when exact colour reproduction matters.

Measure contrast for the text/background combinations actually proposed; do not accept an LLM's uncomputed pass/fail label. Document context and relevant targets, and adjust pairs without unnecessarily destroying the palette. Verify current accessibility standards when reporting compliance.

## Make a board that sells one idea

Show the concept name/story, a short strategy link, colour roles, real type samples, and curated image/mark/texture references. Use consistent comparison structure, clear hierarchy, labels, and breathing room. A stranger should understand the direction quickly without narration. Label references, sketches, and final work accurately.

Keep the concept boards distinct until selecting a direction. A rough generated collage can inform exploration, but inspect it before presenting it as a coherent moodboard. Record the chosen direction and why, including what is deliberately rejected, before scaling production.
