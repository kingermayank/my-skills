# AI Branding — setup guide

Download the ZIP for Codex or Claude Code. Download the portable Markdown file for Grok or another assistant that accepts attached instructions.

## Codex

Unzip `ai-branding.zip`. Place the resulting `ai-branding` folder inside `~/.agents/skills/`, keeping `SKILL.md` and all supporting references together. Start a new Codex session, then ask:

`Use $ai-branding to help me develop a brand for [your brief].`

## Claude Code

Unzip the ZIP and place the `ai-branding` folder inside `~/.claude/skills/`. Start a new Claude Code session and ask:

`/ai-branding Help me develop a brand for [your brief].`

For a skill shared by a project, place the folder inside that project's `.claude/skills/` directory instead.

## Grok / Grokbot

Attach `ai-branding-portable.md` to a conversation and ask the assistant to follow it for your branding project. If your bot supports persistent instructions or knowledge files, add the file there according to its documentation. The portable file includes the supporting guidance in one document.

Grokbot products use different import formats. No specific Grokbot integration has been tested; this file is a portable instruction document, not a verified native bot plugin.

## Starting a project

Share the business, audience, offer, goals, constraints, and any existing brand assets. The skill will identify gaps in the brief before progressing through strategy, naming, voice, visual directions, identity, production, and rollout. Review and approve strategic and creative decisions as you go.
