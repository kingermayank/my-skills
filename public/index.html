What’s inside

Brief
Find the real problem. Turn an ambiguous request into a useful reverse brief.
Strategy
Research the audience and competition. Define positioning and brand pillars.
Voice & naming
Give the brand a personality, a language, and a name with something behind it.
Visual direction
Explore distinct concepts through type, colour, imagery, and materials.
Identity
Build marks, icons, and image rules that hold together across a whole system.
Production
Extend a strong first image into a consistent set, with controlled variations.
Rollout & motion
Put the brand to work in campaigns, mockups, and purposeful movement.
Handoff
Keep the reasoning, source trail, and project memory ready for the next agent.

Install

Download the ZIP and extract the ai-branding folder into your user skills directory:

~/.agents/skills/ai-branding/

Then start with a brief:

Use $ai-branding to develop this brand. Here is my brief: [your brief]. Continue from any established decisions.

If the skill doesn’t appear, start a new chat or restart Codex.

Download the ZIP and extract the ai-branding folder into your personal skills directory:

~/.claude/skills/ai-branding/

Open Claude Code and use:

/ai-branding Develop this brand from my brief. Preserve the established name and audience.

This installs a local Claude Code skill. It does not sync to your Claude web account.

Download the single-file version and attach it to a Grok Bot conversation. Then say:

Use the attached AI Branding workflow for this project. Here is my brief: [your brief].

If your account supports private skills, ask the bot to save the workflow as ai-branding.

Grok Bot’s account-level import hasn’t been verified. The single file includes every procedure, so there are no companion files to lose.
